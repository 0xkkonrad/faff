# Faff rebrand

Faff is published at https://kkonrad.com/faff/. The source repository is https://github.com/0xkkonrad/faff. The application, session rating, state fields, CSS selectors, broadcast channel, backup downloads, install metadata, tests, and documentation use the new name.

The provisional identity uses the 01A Loose end mark, IBM Plex Mono, and paper, graphite, and citron colours. All install icons were rendered from the SVG. The logo picker at `/faff/brand/index.html` contains 10 directions with 5 distinct SVG drawings per direction. It supports favourites, small-size checks, paper/ink/citron backgrounds, an app preview, and individual downloads. Choosing a logo in the picker saves a browser preference; it does not change the published app.

## Compatibility

The previous route retains only a redirect page, an updated service worker, and an install manifest. Existing installed windows move to `/faff/`, preserving query parameters and the active page hash. Schema version 1 data is validated and copied into the new `faff` database as schema version 2. The original database is retained. The migration reads the previous database only when Faff has no saved state, and the write transaction checks again so concurrent first opens cannot overwrite each other.

Old-format backups are accepted. Current app logic uses only `faff` rating values and plan fields. The prior name remains only where required to recognize saved data, backup formats, or the old route in compatibility tests. Git history and earlier release snapshots remain available.

## Verification

- All 16 model and migration tests passed.
- The Chromium browser suite passed timer, rating, history, backup, concurrent-window, midnight, responsive, and offline checks.
- All 12 UI regressions passed in Chromium and WebKit.
- PWA updates preserved running, paused, and completed timers in two open windows.
- Rebrand tests loaded the real previous release, updated its worker, and verified the redirect, migrated history and timer, offline reload, old backup import, and protection against stale data reimport. All three timer states passed in Chromium and WebKit.
- The picker passed checks for 10 groups, 50 downloadable SVGs, saved choices, favourites, modal keyboard dismissal, and no horizontal overflow at 390 and 1440 pixels. Desktop and mobile screenshots were inspected.
- The website built successfully with Hugo.

WebKit's offline emulation has a previously reproduced internal error, including with a minimal service worker. The WebKit migration test therefore disconnects the HTTP server to test cached operation. Chromium also tests browser-emulated offline operation. Physical-device install-icon refresh and operating-system suspension were not tested.
